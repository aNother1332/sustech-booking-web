# 预约助手 · 静态前端

运行在 GitHub Pages 上的纯静态页面：通过作者提供的 GitHub 访问令牌，
触发配套**私有引擎仓库**中的 GitHub Actions 工作流，完成场馆预约 / 抢场，并读取运行结果展示。

## 项目说明

本项目包含**本地版**与**网页版**两种形态：

- **本地版**：在本机运行的服务程序（Python 后端 + 本地网页界面），功能完整，适合日常使用；
- **网页版**（即本仓库）：**基于本地版开发，具备本地版的主要功能**——企业微信扫码登录、场馆 / 场地 / 时段浏览、订场（立即预约）、抢场（每晚 20:00 开放后天场次时自动抢）、滑块验证码自动求解、同场馆候补场地自动扩展、每人每日 2 小时上限校验、演练模式等。
- 网页版由**本仓库**（公开静态前端，只承载界面）与一个配套的**私有引擎仓库**（GitHub Actions 后端，负责登录兑换、抢场执行与结果回写）组成。

**网页版入口：https://another1332.github.io/sustech-booking-web/**

> ⚠ **使用前提：网页版必须使用作者（仓库所有者）提供的 GitHub 访问令牌才能使用。**
> 页面虽可公开打开，但所有数据读取与任务触发都经过作者的私有引擎仓库——
> 没有令牌、或使用其他人的令牌，都无法连接、无法执行任何操作。
> 令牌仅保存在使用者自己的浏览器本地（localStorage）。

## 使用（简述）

1. 打开上方入口 → 粘贴**作者提供**的 GitHub 访问令牌（经典令牌勾选 `repo` 权限即可，保存在浏览器 localStorage）
2. 企业微信扫码获取一次性登录链接 → 粘贴保存（链接一次性、约 5 分钟有效，每个操作前需重新扫码）
3. 选择场馆 / 场地 / 时段 → 创建任务 → 页面自动跟踪运行状态并回显结果（订单号等）

详细引导见页面内「说明」区域。

## 安全模型

- 令牌与登录链接仅保存在**使用者的浏览器**中（localStorage），本页面不收集、不上传任何数据到第三方
- 本仓库为纯静态资源（`index.html` + 二维码图片），不包含任何账号信息
- 后端为独立**私有**仓库：工作流与运行数据均在其中，未经授权的访问者无法触发或读取
