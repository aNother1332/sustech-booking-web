# 预约助手 · 静态前端

运行在 GitHub Pages 上的纯静态页面：通过使用者**本人**保存在浏览器中的 GitHub 访问令牌，
触发其配套**私有引擎仓库**中的 GitHub Actions 工作流，完成场馆预约 / 抢场，并读取运行结果展示。

## 使用（简述）

1. 打开页面 → 粘贴 GitHub 访问令牌（经典令牌勾选 `repo` 权限即可，保存在浏览器 localStorage）
2. 企业微信扫码获取一次性登录链接 → 粘贴保存（链接一次性、约 5 分钟有效，每个操作前需重新扫码）
3. 选择场馆 / 场地 / 时段 → 创建任务 → 页面自动跟踪运行状态并回显结果（订单号等）

详细引导见页面内「说明」区域。

## 安全模型

- 令牌与登录链接仅保存在**使用者的浏览器**中（localStorage），本页面不收集、不上传任何数据到第三方
- 本仓库为纯静态资源（`index.html` + 二维码图片），不包含任何账号信息
- 后端为独立**私有**仓库：工作流与运行数据均在其中，未经授权的访问者无法触发或读取

## 文件

| 文件 | 说明 |
